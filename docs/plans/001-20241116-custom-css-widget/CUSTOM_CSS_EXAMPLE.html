🎨 Personalizar el Widget de Chatwoot con customCSS

✅ Nueva Funcionalidad: Ahora puedes personalizar completamente el estilo del widget de Chatwoot incluyendo el botón "Start Conversation" usando el parámetro customCSS.

📝 Ejemplo 1: Personalizar el Botón "Start Conversation"

Este es el ejemplo más común: cambiar el color, padding, border-radius y hover del botón.

<!DOCTYPE html>
<html>
<head>
    <script>
        (function(d, t) {
            var BASE_URL = "https://tu-dominio.com";
            var g = d.createElement(t), s = d.getElementsByTagName(t)[0];
            g.src = BASE_URL + "/packs/js/sdk.js";
            g.async = true;
            s.parentNode.insertBefore(g, s);
            g.onload = function() {
                window.chatwootSDK.run({
                    websiteToken: "tu-website-token",
                    baseUrl: BASE_URL,
                    customCSS: `
                        /* Personalizar el botón "Start Conversation" */
                        button[class*="inline-flex"] {
                            background-color: #8caca1 !important;
                            color: #ffffff !important;
                            border-radius: 8px !important;
                            padding: 10px 16px !important;
                            border: none !important;
                        }

                        button[class*="inline-flex"]:hover {
                            background-color: #7a9690 !important;
                            box-shadow: 0 4px 12px rgba(140, 172, 161, 0.3) !important;
                        }

                        button[class*="inline-flex"]:active {
                            transform: scale(0.98) !important;
                        }
                    `
                })
            }
        })(document, "script");
    </script>
</head>
<body>
    <h1>Mi Sitio Web</h1>
    <p>Bienvenido! El chat de soporte está abajo a la derecha.</p>
</body>
</html>

Resultado: El botón tendrá:

  • 🎨 Fondo verde (#8caca1)
  • ✍️ Texto blanco
  • ⌘ Border radius: 8px
  • 📏 Padding: 10px 16px
  • ✨ Hover con sombra y color más oscuro

📝 Ejemplo 2: Temas Personalizados Avanzados

Personaliza múltiples elementos del widget simultáneamente.

window.chatwootSDK.run({
    websiteToken: "tu-website-token",
    baseUrl: BASE_URL,
    customCSS: `
        /* Contenedor principal del widget */
        .flex.flex-col.justify-end {
            border-radius: 16px !important;
            box-shadow: 0 10px 40px rgba(0, 0, 0, 0.2) !important;
        }

        /* Botón principal */
        button[class*="inline-flex"] {
            background: linear-gradient(135deg, #8caca1 0%, #7a9690 100%) !important;
            color: white !important;
            border-radius: 8px !important;
            padding: 12px 20px !important;
            font-weight: 600 !important;
            transition: all 0.3s ease !important;
            box-shadow: 0 4px 15px rgba(140, 172, 161, 0.4) !important;
        }

        button[class*="inline-flex"]:hover {
            transform: translateY(-2px) !important;
            box-shadow: 0 8px 20px rgba(140, 172, 161, 0.6) !important;
        }

        /* Iconos dentro del botón */
        button[class*="inline-flex"] i {
            color: white !important;
        }

        /* Mensajes disponibles */
        .text-n-slate-12 {
            color: #2d3748 !important;
        }

        /* Links dentro del widget */
        a {
            color: #8caca1 !important;
        }

        a:hover {
            color: #7a9690 !important;
        }

        /* Inputs y campos de formulario */
        input, textarea {
            border-color: #8caca1 !important;
            border-radius: 6px !important;
        }

        input:focus, textarea:focus {
            outline: none !important;
            border-color: #7a9690 !important;
            box-shadow: 0 0 0 3px rgba(140, 172, 161, 0.1) !important;
        }
    `
})

📝 Ejemplo 3: Dark Mode Personalizado

Aplicar estilos personalizados en modo oscuro.

window.chatwootSDK.run({
    websiteToken: "tu-website-token",
    baseUrl: BASE_URL,
    customCSS: `
        /* En modo oscuro */
        .dark button[class*="inline-flex"] {
            background-color: #5a7a6f !important;
            color: #f0f0f0 !important;
        }

        .dark button[class*="inline-flex"]:hover {
            background-color: #4a6a5f !important;
        }

        .dark .text-n-slate-12 {
            color: #e0e0e0 !important;
        }
    `
})

⚙️ Detalles de Implementación

1. En el SDK (app/javascript/entrypoints/sdk.js)

  • ✅ Se agregó el parámetro customCSS a window.chatwootSettings
  • ✅ Se almacena en window.$chatwoot.customCSS

2. En IFrameHelper (app/javascript/sdk/IFrameHelper.js)

  • ✅ Se pasa customCSS al iframe cuando se recibe el evento 'loaded'
  • ✅ Se envía a través del mensaje 'config-set'

3. En App.vue (app/javascript/widget/App.vue)

  • ✅ Se agregó el método injectCustomCSS()
  • ✅ Se inyecta en el evento 'config-set'
  • ✅ Se crea un <style> con id 'cw-custom-widget-styles'
  • ✅ Se evita inyección duplicada

💡 Tips y Buenas Prácticas

1. Usar !important para sobreescribir estilos

/* ✅ Recomendado */
color: #ffffff !important;

/* ❌ Podría no funcionar */
color: #ffffff;

2. Testear en diferentes navegadores

Asegúrate de probar tu CSS personalizado en:

  • Chrome / Edge
  • Firefox
  • Safari
  • Dispositivos móviles

3. Considerar modo oscuro

/* Modo claro */
button { background-color: #8caca1 !important; }

/* Modo oscuro */
.dark button { background-color: #5a7a6f !important; }

4. Usar transiciones suaves

button {
    transition: all 0.3s ease !important;
}

5. Mantener CSS legible

  • Usa variables CSS cuando sea posible
  • Comenta secciones principales
  • Mantén el CSS minificado en producción

🐛 Troubleshooting

Los estilos no se aplican

  • Verifica que uses !important
  • Abre DevTools (F12) y busca el elemento #cw-custom-widget-styles
  • Comprueba que el CSS sea válido

El botón no es clickeable después de personalizar

  • Asegúrate de no establecer pointer-events: none
  • Verifica que la propiedad cursor sea correcta

Los cambios no aparecen en el iframe

  • Limpia el caché del navegador (Ctrl+Shift+Delete)
  • Verifica que el parámetro se pase correctamente al chatwootSDK.run()
  • Revisa la consola del navegador para errores
